# کاتالوگ محصولات و محاسبه مقدار

کاتالوگ شامل ۶ محصول دریافت‌شده از منبع تأمین و ۶ خانواده قبلی است. شناسه‌های قبلی برای سازگاری با درخواست‌ها و لینک‌ها ثابت‌اند. هر ۱۹ تصویر اصلی نگهداری شده است.

| شناسه | محصول | تصاویر | واحد درخواست اولیه |

| VN-1220 | پشم سنگ | ۴ | مترمربع |

| VN-1216 | توری پلاستیکی و مرغی | ۴ | رول |
| VN-1213 | کارتن‌پلاست | ۴ | ورق |

## هویت سایت و منابع

تمام متن‌ها، معرفی محصولات، گالری، فیلترها، metadata و خروجی مدیریت فقط با هویت پاداش نمایش داده می‌شوند. نشانی تصاویر عمومی `/images/products/` است. اطلاعات قابل استفادهٔ برنامه در `lib/product-images.json` فقط شناسه، مسیر محلی و ابعاد تصویر است.

فهرست نشانی‌های منبع، تاریخ بررسی و SHA-256 تصاویر صرفاً در مستند داخلی `docs/catalog-source.json` باقی می‌ماند؛ این فایل از برنامه import نمی‌شود و در پوشه public نیست. معرفی محصولات در `lib/partner-products.ts` است. قیمت و موجودی قطعی بدون تأیید وارد نشده‌اند؛ قیمت‌ها استعلامی‌اند.

## محاسبه‌گر

`/calculator?product=vn-1213` نمونه پیوند مستقیم به پروفایل محصول است. هر شش محصول تازه به‌اضافه الاستومری در محاسبه‌گر قابل انتخاب‌اند. برای پشم شیشه و پشم سنگ، شکل عرضهٔ رول و ورق پشتیبانی می‌شود. کدهای قدیمی `GW-F`، `RW-S` و `PE-R` نیز به گروه مناسب می‌رسند. مقاطع لوله‌ای کارخانه‌ای با دورپیچ ورق یکسان فرض نشده‌اند.

- ابعاد محصولات جدید خالی‌اند و باید از برچسب مدل منتخب وارد شوند. اندازه‌های واقعی حداکثر تا میلی‌متر پذیرفته می‌شوند و محاسبه گردکردن با اعداد صحیح BigInt انجام می‌شود.
- حالت مساحت آماده، حداقل تعداد واحد از مساحت خالص، لایه‌ها، افزوده و ذخیره را می‌دهد.
- حالت سطح مستطیلی، تعداد سطوح، لایه‌ها و هم‌پوشانی دو جهت را لحاظ می‌کند. ردیف اول تمام عرض واحد را پوشش می‌دهد و هم‌پوشانی فقط بین ردیف‌ها کسر می‌شود.
- نوارهای کامل کوتاه‌تر از رول می‌توانند از رول مشترک برش بخورند. بخش برش‌نخوردهٔ رول ابتدا برای مساحت افزوده و ذخیره استفاده می‌شود. در ورق یا سطح بلندتر از رول، شبکهٔ واحدهای کامل محاسبه می‌شود؛ دورریزها دوباره مصرف نمی‌شوند. چرخش ۹۰ درجه اختیاری است و دو جهت یکنواخت را مقایسه می‌کند.
- ذخیره برنامهٔ برش بر مصرف برش به‌اضافهٔ مساحت افزوده اعمال می‌شود. باقی‌ماندهٔ برش‌نخورده به صورت مساحتی در نظر گرفته می‌شود؛ شکل قطعات خاص و چیدمان مختلط باید جدا بررسی شوند. خروجی تضمین بهینه‌ترین برش نیست.
- دورپیچ لوله همچنان از نوار واقعی هم‌ضخامت، برش یک‌تکه و اتصال لب‌به‌لب در امتداد لوله استفاده می‌کند. هر لایه جدا محاسبه می‌شود.

روش‌ها، مثال‌های مستقل و منابع سازندگان در راهنمای `/guides/roll-insulation-quantity` توضیح داده شده‌اند. درصد پرت و هم‌پوشانی استاندارد همگانی تعیین نشده است.

## به‌روزرسانی دستی

```powershell
node scripts/import-products.mjs
```

این فرمان منابع عمومی را می‌خواند، نسخه خام را در `.sites-runtime/catalog-import` قرار می‌دهد و تصاویر، سند منبع داخلی و metadata خنثای تصاویر را به‌روزرسانی می‌کند. همگام‌سازی یا انتشار خودکار ندارد. تغییر تعداد یا شناسه‌های منبع به بازبینی معرفی‌ها نیاز دارد؛ کنترل سازگاری مانع جاافتادن محصول جدید در بیلد می‌شود.

```powershell
npm.cmd run test:calculator
npm.cmd run build
npm.cmd run typecheck
npm.cmd run test:integration
```

آزمایش محاسبه‌گر شامل مرزهای اعشاری، هم‌پوشانی، برش، ذخیره، چرخش و ۵۰۰ حالت بررسی پوشش است. آزمایش یکپارچه، هویت صفحات و سئو، پروفایل محصول، سلامت و ارائه تصاویر، ثبت سفارش و نمایش در مدیریت و CSV را بررسی می‌کند.
